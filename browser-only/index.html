Share a desktop directly between modern browsers on the same local network. No app installation, account, signaling server, or public relay is required. You exchange a short connection file or text between the two devices to pair them.

ⓘ
Browser-only limitation: this version streams video in view-only mode. Browsers do not let websites control the operating system's mouse or keyboard. Full remote control still requires the desktop app or a native helper. Keep offer/answer text private; it contains connection details for your local network.
